## Status Definitions

- **Not Started**: GDD 不存在
- **In Design**: GDD 起草中
- **In Review**: GDD 已完成，正在审查
- **Approved**: 审查通过，可实现
- **NEEDS REVISION**: 审查发现问题，需修订
